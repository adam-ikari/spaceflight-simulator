# 真实世界登月任务模拟 — 设计（2026-11-20）

## 意图

把观赏型模拟器扩展为完整载人登月任务：地球发射 → 地球停泊轨道 → 地月转移 → 月球轨道捕获 → 月面下降着陆 → 月面起飞 → 月球轨道交会 → 返回地球转移 → 再入着陆。用户明确要求“真实世界的模拟”：所有高度、速度、轨道、着陆状态必须由引力与推力积分得出，不允许脚本跳相或把物理量直接赋值成目标值。

## 真实世界基线

- 参考系：地心惯性系（ECI），z 轴为地球自转轴；任务平面取 x-y 平面。
- 引力：地球点质量 μ⊕ = 3.986004418e14 m³/s²；月球点质量 μ☾ = 4.9048695e12 m³/s²，半径 1737.4 km，半长轴 384400 km，平均角速度 2π/(27.321661 d)。近地段保留地球 J2。
- 积分：RK4 固定步长；转移段同时计入地球与月球引力，月球位置随任务时间解析推进。
- 化学模拟：各级 Isp 不再手填，必须由 `CombustionChemistry` / `PropulsionEngine` 从推进剂、O/F、室压、喷管面积比算出；LM 用 NTO/MMH，上面级用 LOX/LH2，一级用 LOX/RP-1。
- 流体力学：地球上升与返回再入段用 `Atmosphere` 的密度/动压与 `Aerodynamics.dragForceN`（Cd 随马赫数和长细比变化）计算真实气动阻力，阻力进入平移方程。
- 刚体力学：用 `AscentDynamics.simulateAscent` 的级间时序与重力/阻力损失校准上升段俯仰程序与燃尽判据；姿态由推力方向驱动，平移与转动不共用同一个“目标位置赋值”。
- 弹性体力学：动力飞行段用 `StructuralDynamics.pogoResponse` / `randomVibrationGrms` / `minerDamage` 计算机组 pogo、随机振动与疲劳损伤，进入遥测与风险数字，不是装饰文本。
- 推力：有限时长燃烧，a = T/m，ṁ = −T/(Isp·g0)；Isp 由上述化学链算出。燃烧消耗真实推进剂质量，不做瞬时 Δv 占位。
- 制导：TLI/LOI/TEI 用轨道力学目标解算得到燃烧方向与截止条件；月面下降/上升使用闭环控制，按实时高度和速度调整推力方向与节流，真软着陆（触地速度 ≤ 2 m/s）。
- 相位：只由物理事件（距离、相对速度、高度、轨道能量、制导收敛）触发；观赏驻留用墙钟计时，但不能代替物理条件。

## 不引入的范围（明确边界）

- 不引入 JPL DE 星历、太阳/行星引力、月球 mascon 重力场、月球 DEM 地形、6-DOF 姿态动力学；这些需要外部数据或显著更大的内核。若验收要求此层级，需单独追加。
- 现有 LEO 任务保持原样；登月作为并列任务预设，不改变已验证的地球轨道流程。

## 渲染尺度

- 物理坐标始终为真实米/千米，绝不压缩。
- 场景单位按阶段切换：近地/月面段 1 unit = 100 m；转移段 1 unit = 1000 km，地球与月球按真实半径和间距渲染（半径比 6371:1737，距离 384400 km）。巡航段箭体用位置标记，不伪造放大。
- 采用浮原点：航天器始终在原点附近，摄像机按当前天体重新锚定，避免 float32 在 384,400 km 上丢精度。

## 架构

- 新增 `MissionDirector` 接口（`phase`、`step(dt)`、`telemetry()`、`positionKm()`、`setVehicle()`）。现有 `PhysicsDirector` 结构上已满足，保持不变。
- 新增 `LunarDirector` 实现该接口，负责登月相位机、燃烧事件、制导调用与遥测。
- `PlaybackLoop` 按任务预设持有 `MissionDirector`，LEO 分支沿用现有相位推进，LUNAR 分支由 director 自己推进相位。
- `Scene` 新增 `setMission('leo'|'lunar')` 与 `setLunarFrame(...)`，按阶段切换尺度和天体。
- `store` 的遥测增加可选 `body: 'EARTH'|'MOON'`，仅显示用。

## 验证标准

- 物理单测：TLI 解算使航天器在 6 天内进入月球 SOI；下降制导从 100 km 月球圆轨道着陆，触地速度 ≤2 m/s；上升制导进入 100±10 km 月球圆轨道；TEI 返回地球 120 km 以下。
- 全流程测试：`LunarDirector` 从 PAD 到 LANDING 经完整相位，所有相位由物理条件触发，测试跑完不靠强制 `setPhase` 跳过。
- UI 实测：任务预设可选 LEO/登月，登月播放时遥测显示参考天体与真实高度/速度，画面出现月球，暂停/重播/倍速仍工作。
